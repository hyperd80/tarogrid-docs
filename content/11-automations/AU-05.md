*Reference page. The gallery lives in the app (Automation Studio → Recipes); this page teaches you to shop it.*

## What's on the shelf

Every recipe is a pre-written rule — [three slots](#/AU-02), already filled, tested, and explained. The families:

:::cards
- **Selling & dispatch** — confirm ⇒ book courier · delivered ⇒ COD receivable · returned ⇒ notify + restock · stock 0 ⇒ unavailable. The full set with defaults: [the selling cookbook](#/F-23).
- **Risk** — fraud 🔴 ⇒ request advance · advance paid ⇒ confirm · advance expired ⇒ flag for review ([F-24](#/F-24)).
- **Money** — invoice overdue ⇒ remind ([M-05](#/M-05)).
- **Team** — assignee set ⇒ notify them · status-change notifications, so nobody refreshes boards to learn their own work.
:::

More recipes join the gallery over time — cross-module ones (like *delivered ⇒ auto-invoice*) are on the roadmap 🔜.

## Every card answers the same four questions

**What it watches · what it does · what it writes · its default state.** If a card's answers surprise you, don't enable it — each card links its deep article.

## The defaults philosophy

:::note
Recipes that touch money or message customers ship **OFF**. Recipes that only inform you often ship on. Nothing that spends, sends, or promises acts without your deliberate switch — the gallery is a shelf, not a conveyor belt.
:::

## How to shop it

1. Start with the one chore you repeat most — for most shops, that's booking couriers ([S-16](#/S-16)).
2. Read the card's four answers. Flip it on.
3. Watch it run for a day — every action shows in row activity.
4. Add the next recipe once the last one is boring. Boring is the goal.
